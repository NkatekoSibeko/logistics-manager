# Logistics Manager

Internal-style shipment tracker for logistics operations.

## What it does
- Add shipments with customer name, delivery date, and status
- Store records locally in the browser
- List all shipments in a table

## Why this project
I previously built desktop business/logistics systems (Java/C#/PHP/JS + SQL) for Triple N Trading. This is a modern web rebuild of that workflow as public proof of how I design operational software.

## How to run
1. Open `index.html` in a browser
2. Add a shipment
3. Refresh the page — records persist in local storage

## Next features
